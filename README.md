# Soil-Moisture-Based-Plant-Watering-System-with-GSM-alert-using-LPC2129
Soil moisture based automatic plant watering system using NXP LPC2129 (ARM7). A soil moisture sensor controls a DC water pump via L293D driver, status is shown on a 16x2 LCD and LEDs, and a SIM800C GSM module sends SMS alerts and replies to STATUS commands. Embedded C code for Keil.
